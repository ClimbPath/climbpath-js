# ClimbPath JS

**A collection of lightweight, reusable JavaScript libraries built by ClimbPath.**

ClimbPath JS is a public collection of JavaScript libraries and utilities designed to make web development easier. Each library is developed as an independent, reusable component that can be integrated into websites and projects of all kinds — not just ClimbPath.

Use them, adapt them, and build something great.

---

## 📦 Libraries

All libraries are located in the [`/libraries`](./libraries) directory.

Each library has its own directory containing its source code, documentation, examples, and any additional files it needs.

| Directory | Description |
|---|---|
| [`/libraries`](./libraries) | All available JavaScript libraries |

Explore individual library directories to learn about their features, configuration, installation, usage, and requirements.

> More libraries will be added over time.

## ✨ Philosophy

- **Reusable by design** — use libraries in any website or project.
- **Easy to integrate** — keep setup simple and documentation clear.
- **Configurable** — customize behavior and appearance where supported.
- **Independent** — libraries can be used separately without requiring the entire repository.
- **Open source** — publicly available for developers to explore and use.

## 🚀 Getting started

1. Browse the [`/libraries`](./libraries) directory.
2. Open the directory of the library you want to use.
3. Read its `README.md` for installation and usage instructions.
4. Check its license before integrating it into your project.

Depending on the library, you may be able to use it directly in a browser, include it in your existing JavaScript project, or install it using a package manager if one is supported.
